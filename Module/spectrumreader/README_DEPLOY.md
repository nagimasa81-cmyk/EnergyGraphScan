# Energy Graph Simple v2 — PWA Distribution RC

Deploy all runtime files in this folder together at the same HTTPS path.

Runtime files:
- index.html
- app.css
- app.js
- worker.js
- egs-v2-core.bundle.js
- manifest.webmanifest
- version.json
- sw.js

Do not edit `egs-v2-core.bundle.js` manually. It is generated and validated in the SOURCE package.

This distribution contains no regression images, development reports, Node test dependencies, or legacy v1 logic.
